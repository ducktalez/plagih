# PLAGIH

PLAGIH stands for PLAusible Genetic Improvements to Heuristics.
This is a Project resulting from my Masters Thesis (with yet unknown name). Its aim is to provide a framework where a heuristic is improved by genetic programming towards a machine learned approach. The new code shall both perform significantly better and also be an explainable, plausible addition to the original program which the feveloper does understand.
